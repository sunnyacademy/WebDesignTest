本問Q01

HTMLの役割として最も適切なものはどれか

答えと解説を見る
⭕ 正解【B】 Webページの構造を定義する
解説

JavaScript = 動き

本問Q07

答えと解説を見る
⭕ 正解【C】 `<img>`
解説

画像を表示する基本のタグは `<img>` です。`src` は画像の場所を指定する属性であり、タグではありません。`<picture>` はレスポンシブ画像などで使われますが、3級の基本ではまず `<img>` を押さえます。

よくあるミス

英単語として分かりやすい `<image>` を選んでしまう。また、`src` はタグではなく属性である点を混同しやすい。

ポイント

画像タグ = `<img>`

画像の場所 = `src` 属性

宿題 アレンジHA03

次のうち、1つ上の階層にあるimagesフォルダ内のcat.pngを表示する正しい書き方はどれか

答えと解説を見る
⭕ 正解【B】
解説

`../` は1つ上の階層を表します。そこにある `images` フォルダ内の `cat.png` なので、`../images/cat.png` です。

よくあるミス

同じ階層の指定 `images/cat.png` と混同する。

ポイント

1つ上 = `../`

宿題 アレンジHA04

次のうち、HTMLの入れ子として正しいものはどれか

答えと解説を見る
⭕ 正解【C】
解説

タグは、後から開いたものを先に閉じます。`div` の中に `p` を入れるなら、先に `</p>`、その後に `</div>` です。

よくあるミス

閉じタグが交差してしまう。

ポイント

外 → 内 → 内 → 外

宿題 アレンジHA05

次のうち、alt属性の使い方として最も適切なものはどれか

※意味のある写真の場合

答えと解説を見る
⭕ 正解【A】
解説

意味のある画像には、内容が伝わる代替テキストを書くのが適切です。装飾だけの画像では空のaltを使うこともありますが、意味のある写真では説明を入れるのが基本です。

よくあるミス

何でも `alt=""` にしてしまう。

ポイント

意味のある画像には説明を書く

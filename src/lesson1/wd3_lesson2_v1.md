## Q01
CSSの役割として最も適切なものはどれか

【A】 Webページの構造を定義する  
【B】 Webページの見た目を整える  
【C】 サーバーとの通信を行う  
【D】 データを保存する  

⭕ 正解【B】 Webページの見た目を整える

解説  
CSS（Cascading Style Sheets）は、Webページの見た目を整えるための言語です。色、文字サイズ、余白、配置などを指定します。構造はHTML、動きはJavaScriptが担当します。

👉 よくあるミス  
HTMLとCSSの役割を混同して、【A】を選んでしまう。

■ ポイント  
HTML = 構造  
CSS = 見た目  
JavaScript = 動き

## Q02
HTML要素にスタイルを適用する対象を指定するものはどれか

【A】 属性  
【B】 セレクタ  
【C】 URL  
【D】 スクリプト  

⭕ 正解【B】 セレクタ

解説  
セレクタは、CSSを「どのHTML要素に適用するか」を指定するものです。たとえば `p { color: red; }` の `p` がセレクタです。

👉 よくあるミス  
style属性と混同して、【A】を選んでしまう。

■ ポイント  
セレクタ = 対象指定

## Q03

【A】 class  
【B】 id

【D】 src

👉 よくあるミス  
idとclassの役割を逆に覚えてしまう。

■ ポイント  
id = 1つだけ  
class = 複数OK

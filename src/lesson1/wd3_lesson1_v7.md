## Q01
HTMLの役割として最も適切なものはどれか

【A】 Webページの見た目を整える  
【B】 Webページの構造を定義する  
【C】 Webページに動きをつける  
【D】 Webページのデータを保存する  

⭕ 正解【B】 Webページの構造を定義する

解説  
HTML（HyperText Markup Language）は、見出し・段落・画像・リンクなど、Webページの構造を表すための言語です。見た目はCSS、動きはJavaScriptが担当します。

👉 よくあるミス  
「画面に見えるものを作る」という印象から、見た目を担当するCSSと混同して【A】を選んでしまう。

■ ポイント  
HTML = 構造  
CSS = 見た目  
JavaScript = 動き

## Q02
HTMLタグの書き方として正しいものはどれか

【A】 `(p)`  
【B】 `{p}`  
【C】 `<p>`  
【D】 `[p]`  

⭕ 正解【C】 `<p>`

解説  
HTMLタグは `<` と `>` で囲んで書きます。たとえば段落は `<p>`、画像は `<img>` のように書きます。

👉 よくあるミス  
プログラミングで使う `()` や `{}` と混同してしまう。

■ ポイント  
HTMLタグは `< >` で囲む

## Q03
HTMLの基本構造として正しい順番はどれか

【A】 `html → body → head`  
【B】 `html → head → body`  
【C】 `body → html → head`  
【D】 `head → body → html`  

⭕ 正解【B】 `html → head → body`

解説  
HTML文書は、全体を `<html>` で囲み、その中にページ情報を書く `<head>` と、画面に表示される内容を書く `<body>` を置きます。

👉 よくあるミス  
画面に見えるbodyを先に書きたくなり、headとbodyの順番を逆にしてしまう。

■ ポイント  
`html` の中に `head` と `body`

## Q07
画像を表示するタグはどれか

【A】 `<image>`  
【B】 `<picture>`  
【C】 `<img>`  
【D】 `<src>`  

⭕ 正解【C】 `<img>`

解説  
画像を表示する基本のタグは `<img>` です。`src` は画像の場所を指定する属性であり、タグではありません。`<picture>` はレスポンシブ画像などで使われますが、3級の基本ではまず `<img>` を押さえます。

👉 よくあるミス  
英単語として分かりやすい `<image>` を選んでしまう。また、`src` はタグではなく属性である点を混同しやすい。

■ ポイント  
画像タグ = `<img>`  
画像の場所 = `src` 属性

## K02
Web上のページやファイルの場所を示すものはどれか

【A】 HTML  
【B】 XML  
【C】 URL  
【D】 UML  

⭕ 正解【C】 URL

解説  
URL（Uniform Resource Locator）は、Web上のページやファイルの場所を示す文字列です。HTMLやXMLは文書やデータの書き方、UMLは設計図を表すための記法です。

👉 よくあるミス  
Webに関係する用語をまとめて同じものだと思ってしまう。

■ ポイント  
URL = 場所  
HTML = 構造  
XML = データ記述  
UML = 設計記法

## K03
WebブラウザとWebサーバーが通信するときのルールはどれか

【A】 TCP/IP  
【B】 UDP  
【C】 HTML  
【D】 HTTP  

⭕ 正解【D】 HTTP

解説  
HTTP（HyperText Transfer Protocol）は、WebブラウザとWebサーバーが通信するときのルールです。TCP/IPは通信の基盤、UDPは通信方式の一つ、HTMLはページ構造を表す言語です。

👉 よくあるミス  
通信に関係するTCP/IPやUDPを、Webページ取得そのもののルールだと思ってしまう。

■ ポイント  
HTTP = Web通信のルール  
TCP/IP = 通信の基盤  
UDP = 通信方式  
HTML = ページ構造

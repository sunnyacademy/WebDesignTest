Q01

HTMLの役割として最も適切なものはどれか

【A】 Webページの見た目を整える
【B】 Webページの構造を定義する
【C】 Webページに動きをつける
【D】 Webページのデータを保存する
⭕ 正解【B】 Webページの構造を定義する
解説

HTML（HyperText Markup Language）は、見出し・段落・画像・リンクなど、Webページの構造を表すための言語です。見た目はCSS、動きはJavaScriptが担当します。

よくあるミス

「画面に見えるものを作る」という印象から、見た目を担当するCSSと混同して【A】を選んでしまう。

ポイント

HTML = 構造

CSS = 見た目

JavaScript = 動き

Q02

HTMLタグの書き方として正しいものはどれか

【A】 (p)
【B】 {p}
【C】 <p>
【D】 [p]
⭕ 正解【C】 <p>
解説

HTMLタグは < と > で囲んで書きます。たとえば段落は <p>、画像は <img> のように書きます。

よくあるミス

プログラミングで使う () や {} と混同してしまう。

ポイント

HTMLタグは < > で囲む

Q03

HTMLの基本構造として正しい順番はどれか

【A】 html → body → head
【B】 html → head → body
【C】 body → html → head
【D】 head → body → html
⭕ 正解【B】 html → head → body
解説

HTML文書は、全体を <html> で囲み、その中にページ情報を書く <head> と、画面に表示される内容を書く <body> を置きます。

よくあるミス

画面に見えるbodyを先に書きたくなり、headとbodyの順番を逆にしてしまう。

ポイント

html の中に head と body

Q04

ページの大きな見出しとして最も適切なタグはどれか

【A】 <p>
【B】 <div>
【C】 <span>
【D】 <h1>
⭕ 正解【D】 <h1>
解説

<h1> はページ内の最も大きな見出しを表すタグです。<p> は段落、<div> はまとまり、<span> は文章の一部を表します。

よくあるミス

文字が表示されれば何でもよいと思い、<p> や <div> を選んでしまう。

ポイント

h1 = 大見出し

Q05

段落を表すタグはどれか

【A】 <p>
【B】 <br>
【C】 <h1>
【D】 <div>
⭕ 正解【A】 <p>
解説

<p> はparagraph（段落）の意味です。文章のまとまりを表すときに使います。

よくあるミス

改行のように見えるため、<br> と混同する。

ポイント

p = 段落

br = 改行

Q06

HTMLで改行を表すタグはどれか

【A】 <p>
【B】 <br>
【C】 <hr>
【D】 <div>
⭕ 正解【B】 <br>
解説

<br> は文章の途中で改行を入れるためのタグです。<p> は段落、<hr> は区切り線、<div> はまとまりを表します。

よくあるミス

段落の切り替えと改行を同じものとして考えてしまう。

ポイント

br = line break（改行）

Q07

画像を表示するタグはどれか

【A】 <image>
【B】 <picture>
【C】 <img>
【D】 src
⭕ 正解【C】 <img>
解説

画像を表示する基本のタグは <img> です。src は画像の場所を指定する属性であり、タグではありません。<picture> はレスポンシブ画像などで使われますが、3級の基本ではまず <img> を押さえます。

よくあるミス

英単語として分かりやすい <image> を選んでしまう。

ポイント

画像タグ = <img>

Q08

imgタグで画像ファイルの場所を指定する属性はどれか

【A】 href
【B】 alt
【C】 link
【D】 src
⭕ 正解【D】 src
解説

src はsourceの略で、画像ファイルなどの読み込み元を指定します。リンク先を指定するのは href です。

よくあるミス

リンク先の href と、画像の読み込み元 src を混同する。

ポイント

画像の場所 = src

リンク先 = href

Q09

リンクを作成するタグはどれか

【A】 <img>
【B】 <table>
【C】 <form>
【D】 <a>
⭕ 正解【D】 <a>
解説

<a> タグはanchor（アンカー）の意味で、リンクを作成するために使います。リンク先は href 属性で指定します。

よくあるミス

link という名前のタグを想像してしまうが、リンクを作る基本タグは <a>。

ポイント

<a href="..."> = リンク

Q10

aタグでリンク先を指定する属性はどれか

【A】 src
【B】 url
【C】 href
【D】 link
⭕ 正解【C】 href
解説

href はリンク先を指定する属性です。src は画像などの読み込み元を指定する属性です。

よくあるミス

URLを書くので url 属性だと思ってしまう。

ポイント

リンク先 = href

Q11

alt属性の役割として最も適切なものはどれか

【A】 画像のサイズを指定する
【B】 画像の説明を提供する
【C】 画像の位置を指定する
【D】 画像を読み込む
⭕ 正解【B】 画像の説明を提供する
解説

alt はalternative text（代替テキスト）の意味です。画像が表示されない場合や、音声読み上げを使う人に画像の意味を伝えるために使われます。

よくあるミス

画像に関する属性なので、サイズや位置を指定するものだと思ってしまう。

ポイント

alt = 画像の説明 + アクセシビリティ

Q12

正しいHTMLの入れ子構造はどれか

【A】
<p><strong>文字</strong></p>
【B】
<p><strong>文字</p></strong>
【C】
<strong><p>文字</strong></p>
【D】
<p><strong></p>文字</strong>
⭕ 正解【A】
解説

HTMLでは、後から開いたタグを先に閉じます。<p> の中で <strong> を開いた場合、先に </strong> を閉じてから </p> を閉じます。

よくあるミス

開いた順番と閉じる順番が混ざり、タグの交差が起きる。

ポイント

外 → 内 → 内 → 外

Q13

HTMLのコメントとして正しい書き方はどれか

【A】
// コメント
【B】
/* コメント */
【C】
<!-- コメント -->
【D】
# コメント
⭕ 正解【C】
解説

HTMLのコメントは <!-- コメント --> と書きます。// はJavaScript、/* */ はCSSやJavaScript、# は別の文脈で使われます。

よくあるミス

CSSやJavaScriptのコメント記法と混同する。

ポイント

HTMLコメント = <!-- -->

Q15

Q16

相対パスで ../ が表すものはどれか

【B】 同じ階層

【D】 サイトのトップページ

Q17

【C】 images/img.png
【D】 C:\img.png
⭕ 正解【C】 images/img.png

P01

画像を表示し、代替テキスト「猫の画像」を追加しなさい

初期コード

<img>

⭕ 正答例

<img src="cat.png" alt="猫の画像">
解説

画像を表示するには img タグを使い、画像ファイルの場所は src、画像の説明は alt に書きます。

よくあるミス

alt を省略したり、href で画像を指定してしまう。

HOME

⭕ 正答例

<a href="index.html">HOME</a>
解説

リンクを作るには a タグを使い、リンク先は href 属性で指定します。

よくあるミス

src 属性を使ってしまう。

ポイント

リンク = <a href="...">

P03

同じ階層にあるimagesフォルダ内のsample.pngを表示しなさい

初期コード

<img src="" alt="サンプル画像">

⭕ 正答例

<img src="images/sample.png" alt="サンプル画像">
解説

Web上のページやファイルの場所を示すものはどれか

【B】 CSS
【C】 HTML
【D】 DNS

URL（Uniform Resource Locator）は、Web上のページやファイルの場所を示す文字列です。

よくあるミス

URLとHTMLを同じものだと思ってしまう。

ポイント

URL = Web上の住所

K03

WebブラウザとWebサーバーが通信するときのルールはどれか

【A】 URL
【B】 CSS
【C】 HTTP
【D】 PNG
⭕ 正解【C】 HTTP

HTTP（HyperText Transfer Protocol）は、WebブラウザとWebサーバーが通信するときのルールです。

K04

Webサーバーの役割として最も適切なものはどれか

【A】 Webページを表示するだけのソフト
【B】 文字の見た目を整える仕組み
【C】 画像の代替テキストを書く属性
【D】 Webページのデータを保存し、要求に応じて送る仕組み
⭕ 正解【D】 Webページのデータを保存し、要求に応じて送る仕組み

Webサーバーは、HTMLや画像などのデータを保存し、ブラウザからの要求に応じてデータを送ります。

よくあるミス

ブラウザとサーバーを同じものだと思ってしまう。

ポイント

ブラウザ = 見る側

サーバー = 送る側

K05

ブラウザとサーバーの関係として正しいものはどれか

【A】 どちらも同じ役割である
【B】 ブラウザが要求し、サーバーが応答する
【C】 サーバーがCSSを書き、ブラウザがHTMLを書く
